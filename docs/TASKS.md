## Легенда

| Статус | Значение |
|---|---|
| 🔴 | Открыто, никто не начинал |
| 🟡 | В работе |
| 🟢 | Сделано и проверено |
| 🔒 | Ждёт подписи владельца — **меняет числа** или выкатывает наружу |
| ⏸ | Отложено сознательно, с записанной причиной |

## Как обновлять

1. Меняете статус в таблице — и **в той же правке** дописываете строку в «Журнал» внизу.
2. 🟢 ставится только после проверки, а не после коммита. В колонке «Проверено» — чем именно
   (тест, команда, живой прогон). Пусто в этой колонке при 🟢 — ошибка.
3. Пункт, меняющий выходные числа, не может уйти из 🔒 без отдельной спецификации и подписи.
   Это правило проекта, прецедент A1–A3.
4. Закрывая пункт, который есть в [BACKLOG.md](./BACKLOG.md), закройте его и там. Расхождение
   двух файлов — тот самый дефект, ради которого велся аудит 14.09.

## 6. Скрипт датасета `scripts/dataset-to-xlsx.py`

Найдено `/code-review` 14.09. Файл незакоммичен — работа владельца.

| ID | Задача | Статус | Примечание |
|---|---|---|---|
| **СКР-1** | `is_primary` неверен в 100% строк | 🔴 | `rec['primary_image']` не встречается в `images[]` **ни у одной из 1257 записей**: primary — `.jpg` с CDN, images — `.webp`. Фильтр по флагу даёт логотипы и превью видео |
| **СКР-2** | CSV перетирают друг друга | 🔴 | Имена зашиты с префиксом `robots_`, хотя `.xlsx` из аргумента. Воспроизведено: 1,5 МБ заменены 320 байтами. Лечится `OUT.stem` |
| **СКР-3** | Строки с `=` становятся формулами | 🔴 | Проверено на openpyxl 3.1.5. Данные с made-in-china.com контролирует третья сторона; в CSV это классическая инъекция |
| **СКР-4** | Падения при следующем скрейпе | 🔴 | Управляющий символ в имени характеристики, числовое имя, числовое ключевое слово — каждое роняет весь прогон. `NaN`/`inf` в цене пишутся пустой ячейкой |
| **СКР-5** | Ранжирование и поиск используют разные ключи | 🔴 | `strip().casefold()` против `clean().casefold()` — при расхождении колонка молча пустеет |
| **СКР-6** | Нет `__main__`, зависимости не объявлены | 🔴 | В отличие от соседних скриптов с колокейшн-тестами. `uv`/Python нигде не заявлены; лечится PEP 723 прямо в файле |
