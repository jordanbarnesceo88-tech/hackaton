Номера ниже — номера задач соответствующей вкладки, не номера строк. Таблица описывала опубликованную модель `tz-1.0.4 / sim-1.1.0`; сверка относится к текущим исходникам рабочей ветки после `da53b43`, включая `tz-1.0.7 / warehouse-dense-underlift-1.9.0`. «Реализовано» означает наличие связанной программной цепочки. Старые receipts не подменяют новые результаты.
