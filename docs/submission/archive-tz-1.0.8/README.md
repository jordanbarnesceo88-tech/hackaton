# Исторические проверки tz-1.0.8

В этой папке сохранены прежние протоколы, включая нагрузочные измерения очереди и визуальные проверки. Их версии, ресурсы и область применимости указаны в самих файлах. Они не являются приёмкой текущего выпуска.

Актуальные расчётные выгрузки, презентация, руководство и протоколы находятся в [current](../current/README.md).
