## Исторический принятый пример отчёта

`sample-report.pdf` (30 страниц), CSV/XLSX/PNG и `calculation-source.json` сохранены побайтно как принятый пример **`tz-1.0.3`**. Его проект `cmvcrh7hp000004qqffktuyv7`, сценарий `purchase`, N14/C1, прежний отдельный эксплуатационный пост, NPV −18,356 млн ₽. Это исторический отчёт, а не новый расчёт с дополнительными часами персонала.

Серверная проверка этого входа без учебных инцидентов: 133,5 пал./ч, очередь 0, p95 назначения 1,05 мин. Дополнительный standalone-пример с четырьмя заданными инцидентами даёт 132 пал./ч, p95 1,45 мин. Условия различаются.

`verification-review.json` содержит приёмку прежнего комплекта. Новое дополнение принято отдельно: доказательства текущего review находятся в `economics-verification-review.json`; прежняя подпись на новые файлы не переносилась. Без новых полей денежный движок сохраняет прежнюю арифметику.
