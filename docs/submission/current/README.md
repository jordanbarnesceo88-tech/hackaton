# Сдаточный комплект tz-1.0.10

Этот комплект закрепляет предыдущий проверенный расчёт; новые функции tz-1.1.0 в него ещё не включены. Версии и хеши сохранены в manifest, и результаты прежнего выпуска не объявляются проверкой нового.

20 октября 2026 г.: tz-1.0.10 / sim-1.2.1 / warehouse-dense-underlift-1.9.1.

- [presentation.pdf](./presentation.pdf) — 15 слайдов продукта, алгоритма, источников, архитектуры и плана развития.
- [documentation.pdf](./documentation.pdf) — руководство по функционалу, моделям, данным, архитектуре и запуску.
- sample-report.pdf/csv/xlsx — реальные выгрузки сохранённого N6/C2 проекта.
- [calculation-source.json](./calculation-source.json) — вход, версия, операция и сохранённый результат.
- Три *-receipt.json — реальные серверные ответы; [demo-numbers.md](./demo-numbers.md) содержит числа и допущения.
- [content-coverage.json](./content-coverage.json) — карта обязательного содержания документов; не общий вердикт соответствия.
- [Исторические нагрузочные протоколы](../archive-tz-1.0.8/README.md) — измерения прежнего выпуска с собственными версиями и ресурсами. Регламент текущей очереди — [CALCULATION_JOBS](../../CALCULATION_JOBS.md).
- [release-manifest.json](./release-manifest.json) — SHA256 и границы приёмки.

Номинальный прогон сохранён отдельно как PARTIAL; capacity PASS подтверждает только объявленный контролируемый тест полного цикла. Это кандидат для дальнейшей проверки, без общей рекомендации полного внедрения. Учебные данные не являются коммерческими условиями заказчика. Локальная приёмка не означает обновление внешнего стенда. Исторические протоколы вынесены в отдельный архив; актуальные инструкции находятся в README проекта и docs/DEMO-SCRIPT.md.
